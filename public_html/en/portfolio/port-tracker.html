Project 4.0

During the third year of my studies, I worked on project 4.0, a large project where all 4 parts of IT come together. The goal of the project was to create a live tracking app that displays all ground services equipment in the port of Antwerp.

The Assignment

In the port of Antwerp, various forklift trucks drive around the quays loading and unloading containers from cargo ships. This ensures that there is often considerable chaos, because there are so many different trucks and other moving machines around.

The goal of our project is to develop a system where we can see where these vehicles are at all times. Furthermore, using artificial intelligence, we need to create a subsystem that can tell if a vehicle is malfunctioning.

Analysis Phase

For this project, our team spent eight weeks on the analysis phase. Each week we had one afternoon to work on this. Everyone had done research on certain aspects that were important in the project. We then sat together to discuss this in detail and it was then written down in the analysis document. After the analysis phase we were given four weeks to work out the project effectively.

  • Preparing for the first meeting with the client
  • Plan of approach
  • Presentation Plan of Action

Realization phase

During the realization phase, my job was to develop the app. For this, I created the front-end in Flutter, a system that was brand new to me at the time. My colleagues simultaneously created the back-end in Golang, the hosting with AWS and a QR code generator.

The application was a success, due to Google Maps integration the app worked as was expected. One could get into a vehicle, scan the QR code that causes live tracking to start, and perform the task. Finally when they leave the vehicle, using the app, the final location of the vehicle is stored in the database.

In addition to this I also helped create the video explaining the application and the website for during the presentation of our project.
