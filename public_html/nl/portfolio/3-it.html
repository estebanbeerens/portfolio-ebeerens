Werkervaring als student

Bij 3-It kwam ik in november 2019 terecht als jobstudent full-stack developer. Hier kreeg ik de kans om onder betaling bij te leren en te werken voor klanten. Meestal werkte ik hier één dag in de week om het werken te combineren met mijn studies, maar wanneer ik meer tijd had werkte ik hier volledige maanden.

Ik stond voornamelijk in voor de Angular front-end met NgRx, waar mijn perfectionisme en gevoel voor UI/UX het beest naar voor kwam. Ik was verantwoordelijk voor de look & feel van de applicatie. Hiernaast maakte ik ook regelmatig veranderingen in de .NET back-end.

Jammer genoeg kan ik de applicaties die ik gemaakt heb voor 3-It niet laten zien omdat deze code vertrouwelijk is voor de klant.
