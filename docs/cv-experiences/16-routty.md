# Routty

**Organisation:** Routty  
**Role:** Front-end product developer  
**Period:** September 2021–May 2022

## Korte beschrijving (NL)

Ik migreerde Routty's front-end van een maatwerk-JavaScriptframework naar Angular 13, verbeterde de UI/UX en integreerde nieuwe functies. Ook werkte ik aan PHP-koppelingen, SQL-upgradescripts en uitbreidingen van de .NET API.

## Short description (EN)

I migrated Routty’s front end from a custom JavaScript framework to Angular 13, improved the UI/UX and integrated new features. I also worked on PHP communication, SQL upgrade scripts and .NET API extensions.

## Volledige beschrijving (NL)

Routty is een SaaS-platform voor het ontvangen, verzenden en verwerken van financiële gegevens en bijbehorende goedkeurings- en archiveringsworkflows. Ik werkte aan de front-end en de koppeling met de achterliggende diensten.

Ik migreerde de front-end van het maatwerk-JavaScriptframework naar Angular 13 en testte en beoordeelde ontwikkelwerk. Daarnaast verbeterde ik de UI/UX, integreerde ik productfuncties, werkte ik aan servercommunicatie via PHP en schreef ik SQL-migratie- en upgradescripts. Ook leverde ik kleine uitbreidingen aan de .NET API. De broninformatie noemt geen meetbare performance-, gebruiks- of adoptieresultaten, dus die worden hier niet verondersteld.

## Full description (EN)

Routty is a SaaS platform for receiving, sending and processing financial data, including related approval and archiving workflows. I worked on the front end and its communication with back-end services.

I migrated the front end from a custom JavaScript framework to Angular 13 and tested and reviewed development work. I also improved the UI/UX, integrated product features, worked on server communication through PHP and wrote SQL migration and upgrade scripts. I delivered small extensions to the .NET API as well. The available source information does not include measurable performance, usability or adoption results, so none are assumed here.
