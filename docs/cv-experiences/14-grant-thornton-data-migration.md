# Internal data migration

**Organisation:** Grant Thornton Belgium  
**Role:** Software developer  
**Period:** July–September 2022

## Korte beschrijving (NL)

Ik migreerde duizenden records met Java-scripts en hield het oude en nieuwe systeem daarna automatisch gesynchroniseerd. Dagelijkse nachtelijke taken voorkwamen handmatige invoer van nieuwe records in het nieuwe systeem.

## Short description (EN)

I migrated thousands of records with Java scripts and kept the old and new systems automatically synchronised afterwards. Nightly jobs avoided manually re-entering new records in the new system.

## Volledige beschrijving (NL)

Grant Thornton België moest een aanzienlijke hoeveelheid gegevens uit een oud systeem naar een nieuw systeem migreren. Het ging om duizenden records, waaronder records die automatisch moesten worden aangevuld.

Ik volgde het project op, besprak vervolgstappen, ontwikkelde Java-scripts en bewaakte de migratieprestaties. Eerst voerden we een grote bulkdatamigratie uit. Daarna hielden geplande nachtelijke taken het oude en nieuwe systeem synchroon, zodat records die in het oude systeem werden toegevoegd niet handmatig opnieuw in het nieuwe systeem hoefden te worden ingevoerd. Deze synchronisatie bleef voor onbepaalde tijd actief.

## Full description (EN)

Grant Thornton Belgium needed to move a substantial amount of data from a legacy system to a new one. This involved thousands of records, including records that needed to be completed automatically.

I tracked the project, discussed next steps, developed Java scripts and monitored migration performance. We first ran a large bulk migration. Scheduled nightly jobs then kept the old and new systems synchronised, so records added to the legacy system did not need to be re-entered manually in the new system. This synchronisation remained active indefinitely.
