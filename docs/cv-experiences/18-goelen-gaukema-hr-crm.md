# HR CRM web app

**Organisation:** 3-it — reusable HRM template; Goelen & Gaukema HR Partners (client)  
**Role:** Lead front-end developer  
**Period:** May 2020–January 2021

## Korte beschrijving (NL)

Ik leidde de Angular-front-end voor een HR-CRM-template die 3-it voor drie à vier klanten hergebruikte. Hergebruik verkortte de ontwikkeling van vergelijkbare applicaties van enkele maanden tot enkele weken en verbeterde consistentie.

## Short description (EN)

I led the Angular front end for an HR CRM template that 3-it reused for three to four clients. Reuse shortened development of similar applications from several months to several weeks and improved consistency.

## Volledige beschrijving (NL)

Goelen & Gaukema HR Partners was 3-it's largest client for a reusable HRM application template. The CRM supported internal and external processes, integrated existing Azure data and provided Microsoft sign-in. 3-it owned the template's intellectual property; clients did not pay the full cost of developing the reusable core.

Ik leidde de Angular-front-end, structureerde de applicatie voor hergebruik en bouwde componenten en state management met NgRx. Ik beoordeelde UI- en CSS-wijzigingen, implementeerde Microsoft-aanmelding en voerde kleine wijzigingen door in de .NET OpenAPI. Het template werd aangepast voor drie à vier klanten. Door die herbruikbare basis daalde de ontwikkelingstijd voor vergelijkbare applicaties van enkele maanden naar enkele weken, terwijl de oplossingen consistenter bleven.

## Full description (EN)

Goelen & Gaukema HR Partners was 3-it’s largest client for a reusable HRM application template. The CRM supported internal and external processes, integrated existing Azure data and provided Microsoft sign-in. 3-it owned the template’s intellectual property; clients did not pay the full cost of developing the reusable core.

I led the Angular front end, structured the application for reuse and built components and NgRx state management. I reviewed UI and CSS changes, implemented Microsoft sign-in and made small changes to the .NET OpenAPI. The template was adapted for three to four clients. This reusable foundation reduced development time for similar applications from several months to several weeks while improving consistency.
