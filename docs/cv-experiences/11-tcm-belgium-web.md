TCM Belgium beheert onbetaalde factuurvorderingen voor klanten. De organisatie werkte met een maatwerksysteem in Java dat ondersteuning nodig had voor nieuwe wetgeving en efficiëntere interne workflows.

Ik werkte aan uitbreidingen van het bestaande systeem en verbeteringen aan langdurige werkprocessen. Ik coachte één andere consultant. De gevraagde wijzigingen werden binnen de deadline opgeleverd; concrete cijfers over tijdsbesparing zijn niet beschikbaar.

## Full description (EN)

TCM Belgium manages unpaid invoice claims on behalf of clients. The company relied on a custom Java system that needed updates for new legislation and more efficient internal workflows.

I worked on extensions to the existing system and improvements to lengthy workflows. I coached one other consultant. The requested changes were delivered by the deadline; no figures for time saved are available.
