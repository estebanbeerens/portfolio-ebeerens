# Templating tool

**Organisation:** Democo Group  
**Role:** Power Apps developer  
**Period:** August 2022–May 2023

## Korte beschrijving (NL)

Ik bracht een productieproces voor documentsjablonen terug van meerdere uren werk per week tot enkele minuten. Een kleine groep key users gebruikte hiervoor een Power App met SharePoint en een .NET Azure Function.

## Short description (EN)

I reduced a document-templating process from several hours of work per week to a few minutes. A small group of key users used a production Power App with SharePoint and a .NET Azure Function.

## Volledige beschrijving (NL)

Democo Group wilde een verouderde, onoverzichtelijke tool voor documentsjablonen vernieuwen. Ik bouwde een Power App die gegevens uit SharePoint gebruikt en ontwikkelde een .NET Azure Function om Word-documenten naar het gewenste formaat te verwerken.

De Power App werd in productie genomen en gebruikt door een kleine groep key users. Door enkele waarden in te voeren konden zij binnen seconden het juiste Word-sjabloon genereren. Volgens mijn herinnering daalde het werk aan sjablonen van meerdere uren per week tot enkele minuten per week. Het aantal gebruikers was bewust beperkt tot de key users; een groter bereik of een bedrijfsaantal is niet van toepassing.

## Full description (EN)

Democo Group wanted to replace an outdated, cluttered document-templating tool. I built a Power App that uses SharePoint for data and developed a .NET Azure Function to process Word documents into the required format.

The Power App went into production and was used by a small group of key users. By entering a few values, they could generate the correct Word template within seconds. To the best of my recollection, the work involved in preparing templates fell from several hours per week to a few minutes per week. Use was intentionally limited to key users; a wider user or company-size estimate is not applicable.
