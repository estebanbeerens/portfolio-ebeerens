Ik maakte van mijn statische cv een live, tweetalig full-stack portfolio met een beveiligde beheeromgeving. Ontworpen in Figma en gelanceerd in september 2026, groeide het leerproject uit tot een productieplatform dat ik bijna volledig AI-native bouwde.

## Short description (EN)

I turned my static CV into a live, bilingual full-stack portfolio with a secure admin interface. Designed in Figma and launched in September 2026, the learning project grew into a production platform built almost entirely with an AI-native approach.

## Volledige beschrijving (NL)

Mijn eerdere portfolio was statisch en bevatte weinig informatie. Ik begon dit project om nieuwe vaardigheden te leren en mijn projecten, ervaring, vaardigheden en profielinformatie zelf te kunnen beheren. Het groeide uit tot een compleet full-stack platform dat sinds september 2026 live staat op [ebeerens.com](https://ebeerens.com).

Ik schetste de applicatie in Figma en gebruikte Figma MCP om componenten en schermen te maken die nauw aansluiten op het ontwerp. Vervolgens bouwde ik de applicatie bijna volledig met AI, in een AI-native workflow waarin Copilot skills, projectinstructies en specificaties de basis vormden voor een schaalbare oplossing.

Het resultaat is een tweetalige portfolio-website met server-side rendering, een beveiligde beheeromgeving en een API met database. Ik realiseerde onder meer GitHub OAuth met server-side sessies, een contactformulier met Cloudflare Turnstile, objectopslag voor afbeeldingen en documenten en een getypeerde API-client op basis van het OpenAPI-contract.

Naast productontwikkeling bouwde ik de productieomgeving en deploymentstraat. Ik leerde een eigen VPS opzetten, mijn domein via DNS koppelen, de Nx-workspace beheren, applicaties containeriseren en images naar een container registry publiceren, en CI/CD-deployments inrichten. Spec-driven development bleek daarbij essentieel om met AI een consistente en onderhoudbare applicatie op te bouwen. Wat begon als een leerproject groeide zo uit tot een publiek product én een end-to-end leerervaring in ontwerp, full-stackontwikkeling en DevOps.

## Full description (EN)

My previous portfolio was static and contained little information. I started this project to learn new skills and to manage my projects, experience, skills and profile content myself. It grew into a complete full-stack platform, live at [ebeerens.com](https://ebeerens.com) since September 2026.

I sketched the application in Figma and used Figma MCP to create components and screens that closely match the design. I then built the application almost entirely with AI, using an AI-native workflow grounded in Copilot skills, project instructions and specifications to produce a scalable solution.

The result is a bilingual portfolio website with server-side rendering, a secure admin interface and an API backed by a database. I implemented features including GitHub OAuth with server-side sessions, a contact form protected by Cloudflare Turnstile, object storage for images and documents, and a typed API client based on the OpenAPI contract.

I also built the production environment and deployment pipeline. I learned to set up my own VPS, connect my domain through DNS, manage the Nx workspace, containerise applications and publish images to a container registry, and configure CI/CD deployments. Spec-driven development proved essential for using AI to build a consistent, maintainable application. What began as a learning project became both a public product and an end-to-end learning experience in design, full-stack development and DevOps.
