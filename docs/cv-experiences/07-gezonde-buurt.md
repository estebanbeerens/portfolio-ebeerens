# Gezonde Buurt (Healthy Neighbourhood)

**Organisation:** LCM — Sopra Steria  
**Role:** Front-end developer  
**Period:** June–September 2024

## Korte beschrijving (NL)

Ik bouwde de Drupal-subsite Gezonde Buurt voor LCM en ontwikkelde de zoek- en Site Studio-componenten vanaf nul, met maatwerk-JavaScript voor extra interactie. De site werd op tijd opgeleverd.

## Short description (EN)

I built LCM’s Gezonde Buurt Drupal subsite and developed its search and Site Studio components from scratch, adding custom JavaScript for richer interaction. The site was delivered on time.

## Volledige beschrijving (NL)

Als onderdeel van de SLA-ondersteuning voor LCM bouwde ik een nieuwe Drupal-subsite: Gezonde Buurt. Ik richtte de sitestructuur en Search API in en ontwikkelde de zoek- en Acquia Site Studio-componenten vanaf nul. Met maatwerk-JavaScript voegde ik extra interactie toe.

De website werd op tijd opgeleverd, zodat de contentredacteuren van CM de site konden publiceren. De link is [cm.be/gezonde-buurt](https://www.cm.be/gezonde-buurt/).

## Full description (EN)

As part of SLA support for LCM, I built a new Drupal subsite: Gezonde Buurt (Healthy Neighbourhood). I configured the site structure and Search API and developed the search and Acquia Site Studio components from scratch. I added custom JavaScript for richer interaction.

The website was delivered on time, allowing CM’s content editors to publish it. The live site is [cm.be/gezonde-buurt](https://www.cm.be/gezonde-buurt/).
