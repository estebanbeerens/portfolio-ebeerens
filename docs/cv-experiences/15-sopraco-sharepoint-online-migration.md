# SharePoint Online migration

**Organisation:** Sopraco Group  
**Role:** SharePoint developer  
**Period:** July–September 2022

## Korte beschrijving (NL)

Ik ondersteunde Sopraco's overstap naar SharePoint Online met PowerShell en ShareGate, richtte de nieuwe structuur in en bouwde aangepaste componenten. Key users en IT valideerden de migratie aan de hand van controles en migratielogs.

## Short description (EN)

I supported Sopraco’s move to SharePoint Online with PowerShell and ShareGate, set up the new structure and built custom components. Key users and IT validated the migration using checks and migration logs.

## Volledige beschrijving (NL)

Sopraco wilde de samenwerking, documentdeling en informatievoorziening verbeteren door over te stappen naar SharePoint Online. Ik schreef PowerShell-scripts en gebruikte ShareGate om gegevens over te zetten.

Samen Met de klant richtte ik de SharePoint Online-structuur in, verzorgde ik beheer en bouwde ik aangepaste componenten voor SharePoint-pagina's. Key users en het IT-team van Sopraco valideerden de migratie. Daarbij gebruikten we controles, logs van migratietools en de uitgevoerde migratietaken. Het aantal sites, gebruikers en de hoeveelheid data zijn niet gekwantificeerd.

## Full description (EN)

Sopraco wanted to improve collaboration, document sharing and information management by moving to SharePoint Online. I wrote PowerShell scripts and used ShareGate to transfer data.

With the client, I set up the SharePoint Online structure, handled administration and built custom components for SharePoint pages. Sopraco’s key users and IT team validated the migration using checks, migration-tool logs and job records. The number of sites, users and volume of data have not been quantified.
