## Volledige beschrijving (NL)

SQAS (Safety and Quality Assessment for Sustainability) is het beoordelingssysteem van Cefic voor logistieke dienstverleners en distributeurs van chemische producten, onder meer op het gebied van kwaliteit, veiligheid en milieuprestaties. De oude Angular 4-toepassing moest worden vernieuwd. De nieuwe SQAS-applicatie werd opgebouwd binnen een SharePoint Framework-component met Angular en geïntegreerd in Power Pages.

Ik bouwde het merendeel van de zichtbare componenten in zowel Power Pages als de SQAS-applicatie. Daarnaast werkte ik aan Power BI Embedded-uitbreidingen met React, de migratie van SQL Server naar Dataverse met Power Query, een modelgestuurde beheerapp en automatiseringen met Power Automate. Het vernieuwde platform is live en wordt door organisaties in heel Europa gebruikt. De omvang van de migratie is niet gekwantificeerd.

## Full description (EN)

SQAS (Safety and Quality Assessment for Sustainability) is Cefic’s assessment system for logistics service providers and chemical distributors, covering areas such as quality, safety and environmental performance. The old Angular 4 application needed to be modernised. The new SQAS application was built inside a SharePoint Framework component using Angular and integrated into Power Pages.

I built most of the visible components in both Power Pages and the SQAS application. I also worked on Power BI Embedded extensions with React, the SQL Server-to-Dataverse migration using Power Query, a model-driven admin app and Power Automate workflows. The renewed platform is live and used by organisations across Europe. The migration scale is not quantified.
