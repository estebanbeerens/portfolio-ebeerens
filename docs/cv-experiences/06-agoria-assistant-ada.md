# Agoria Assistant (Ada)

**Organisation:** Agoria — Sopra Steria  
**Role:** Front-end developer  
**Period:** September–December 2024

## Korte beschrijving (NL)

Ik bouwde een schaalbare React-chatbotapp en integreerde die in Agoria's Drupal-site. De ledenassistent ging in december 2024 live in het Nederlands, Frans en Engels; AI en API werden door een externe leverancier geleverd.

## Short description (EN)

I built a scalable React chatbot app and integrated it into Agoria’s Drupal site. The member assistant launched in December 2024 in Dutch, French and English; its AI and API were provided by a third party.

## Volledige beschrijving (NL)

Agoria wilde een digitale assistent beschikbaar maken voor leden om informatie op de website te vinden. De assistent is niet publiek toegankelijk; gebruikers hebben een Agoria-lidmaatschap nodig. Het is een React-app die in de Drupal-site is geïntegreerd.

Ik bouwde de schaalbare front-end en integreerde deze met de Drupal-website. De externe leverancier leverde de AI en API; ik implementeerde de API-specificatie die door die leverancier was aangeleverd en synchroniseerde de vertalingen tussen Drupal en React. De assistent wordt actief gebruikt door Agoria-leden en ondersteunt Nederlands, Frans en Engels.

## Full description (EN)

Agoria wanted to provide members with a digital assistant to find information on its website. The assistant is not publicly accessible; users need an Agoria member account. It is a React app integrated into the Drupal site.

I built the scalable front end and integrated it with the Drupal website. A third-party provider supplied the AI and API; I implemented the API specification provided by that vendor and synchronised translations between Drupal and React. The assistant launched in December 2024, is actively used by Agoria members and supports Dutch, French and English.
