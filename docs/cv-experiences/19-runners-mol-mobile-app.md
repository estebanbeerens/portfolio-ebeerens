# Runners mobile app

**Organisation:** Runners Mol  
**Role:** Mobile developer  
**Period:** November 2019–May 2020

## Korte beschrijving (NL)

Ik ontwierp en bouwde een Flutter-app die medewerkers hielp video's van klanten op verschillende hardloopschoenen te vergelijken. De app koppelde aan een bestaande .NET-back-end; productiegebruik is niet bevestigd.

## Short description (EN)

I designed and built a Flutter app to help Runners Mol staff compare customer videos wearing different running shoes. It connected to an existing .NET back end; production use has not been confirmed.

## Volledige beschrijving (NL)

Runners Mol wilde medewerkers video's laten vergelijken van klanten die verschillende hardloopschoenen testten, om hun prestaties te beoordelen. Ik onderzocht geschikte mobiele technologieën, maakte ontwerpvoorstellen in Figma en werkte de applicatiearchitectuur uit.

Vervolgens ontwikkelde ik de app in Flutter en koppelde deze aan de bestaande .NET-back-end. De applicatie was bedoeld om medewerkers te helpen video's te vergelijken en loopprestaties te analyseren. Of de app in productie is gebruikt, is niet bevestigd.

## Full description (EN)

Runners Mol wanted staff to compare videos of customers testing different running shoes and assess their performance. I evaluated mobile framework options, created design mock-ups in Figma and defined the application architecture.

I then developed the app in Flutter and connected it to the existing .NET back end. It was intended to help staff compare videos and analyse running performance. Whether the app was used in production has not been confirmed.
